ОПИСАНИЕ ПРОЕКТА
----------------------------------------------------------------------
Этот модуль является "мозгом" системы видеоаналитики. Он не обучает нейросети, 
а объединяет результаты работы двух независимых моделей (детекция объектов 
и оценка поз) в единый аналитический поток.

Модуль решает главную инженерную задачу хакатона: синхронизацию разрозненных 
данных во времени и пространстве, применение бизнес-логики безопасности 
и генерацию отчетности.

КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ
----------------------------------------------------------------------
1. Data Fusion (Слияние данных):
   Алгоритмическое объединение Bounding Boxes (от YOLO) и Skeletons 
   (от Pose Estimation) для каждого человека в кадре.

2. Умная синхронизация:
   Решение проблемы разных FPS и временных штампов у разных источников данных.

3. Гибридная логика безопасности:
   Определение статуса сотрудника на основе геометрии скелета. Если скелет 
   перекрыт, система автоматически переключается на резервный анализ 
   геометрии "коробки" (Bounding Box).

4. Рендер и Экспорт:
   - Генерация видео с цветовой разметкой событий.
   - Формирование CSV-таблицы для дашборда (Frontend).

СТРУКТУРА ФАЙЛОВ
----------------------------------------------------------------------
[ main.py ]              - Точка входа. Цикл обработки видео и синхронизация.
[ logic.py ]             - Математическое ядро. Геометрия и проверки состояний.
[ input_video.mov ]      - Исходное видео (12 минут).
[ final_report.json ]    - Входные данные детекции (ID, координаты, роли).
[ fedya_pose.json ]      - Входные данные поз (Ключевые точки скелета).
[ hackathon_result.csv ] - ВЫХОД: Таблица событий для веб-интерфейса.
[ final_output.avi ]     - ВЫХОД: Готовое видео с инфографикой.

ИНСТРУКЦИЯ ПО ЗАПУСКУ
----------------------------------------------------------------------
Для работы требуется Python 3.8 или новее.

1. Установите необходимые библиотеки:
   pip install opencv-python pandas numpy

2. Убедитесь, что файлы 'final_report.json' и 'fedya_pose.json' 
   находятся в папке с скриптом.

3. Запустите обработку:
   python main.py

Внимание: Процесс обработки 12-минутного видео занимает время. 
Прогресс (номер кадра) будет отображаться в консоли.

КАК РАБОТАЕТ ЛОГИКА (LOGIC.PY)
----------------------------------------------------------------------
Система использует каскадную проверку статусов:

ШАГ 1: Matching (Связывание)
Берется "коробка" человека. Внутри нее ищется скелет, чей центр масс или 
ключевые точки попадают в границы коробки.

ШАГ 2: Определение статуса (State Machine)
Система проверяет условия в порядке приоритета опасности:

1. ПРИОРИТЕТ "FALL_DETECTED" (Падение):
   - Если скелет есть: Голова находится на уровне ног ИЛИ человек "распластан" 
     (ширина > высоты).
   - Если скелета нет: Ширина коробки в 1.5 раза больше высоты.

2. ПРИОРИТЕТ "WORKING" (Работа):
   - Проверяется только при наличии скелета.
   - Если запястья (wrists) находятся выше уровня бедер (hips) по оси Y.
   - Интерпретируется как выполнение ручных операций.

3. СТАТУС "IDLE" (Простой):
   - Присваивается во всех остальных случаях (человек стоит, руки опущены).

ЛЕГЕНДА ЦВЕТОВ НА ВИДЕО
----------------------------------------------------------------------
Для удобства оператора используется визуальная кодировка рамок:

[ КРАСНЫЙ ] - FALL_DETECTED (Упал / Лежит). Требуется внимание!
[ ЗЕЛЕНЫЙ ] - WORKING (Работает). Нормальный процесс.
[ ЖЕЛТЫЙ  ] - IDLE (Простой). Сотрудник стоит или идет.
[ СЕРЫЙ   ] - TRAIN (Поезд / Техника).

НАСТРОЙКИ (MAIN.PY)
----------------------------------------------------------------------
В начале файла main.py доступны переменные для тюнинга:

DATA_SPEED_FACTOR = 0.33333

(Сдвиг в кадрах, если данные отстают или опережают видео)
